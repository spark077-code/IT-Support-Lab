# DNS Standards

## RFC 1034

**Title:** Domain Names – Concepts and Facilities

Description:

Defines the concepts and architecture of the Domain Name System (DNS).

Reference:

https://datatracker.ietf.org/doc/html/rfc1034

---

## RFC 1035

**Title:** Domain Names – Implementation and Specification

Description:

Defines DNS resource records, message formats, and communication protocols.

Reference:

https://datatracker.ietf.org/doc/html/rfc1035
