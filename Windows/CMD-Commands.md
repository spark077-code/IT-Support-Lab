# 💻 Windows Command Prompt (CMD) Commands

## 📌 Objective

This document contains essential Windows Command Prompt (CMD) commands commonly used in IT Support, Help Desk, Desktop Support, and Network Troubleshooting.

---

# 🌐 Networking Commands

| Command | Purpose | Example |
|----------|---------|---------|
| ipconfig | Display IP configuration | ipconfig /all |
| ping | Test network connectivity | ping 8.8.8.8 |
| tracert | Trace packet route | tracert google.com |
| pathping | Analyze network path | pathping 8.8.8.8 |
| arp | Display ARP cache | arp -a |
| netstat | Display network connections | netstat -ano |
| nslookup | Query DNS records | nslookup google.com |
| hostname | Show computer name | hostname |
| route | Display routing table | route print |

# 🖥️ System Information Commands

| Command | Purpose |
|----------|---------|
| systeminfo | Display system information |
| tasklist | List running processes |
| taskkill | End a running process |
| driverquery | List installed drivers |
| whoami | Display current logged-in user |
| ver | Show Windows version |

# 🔒 User Management Commands

| Command | Purpose |
|----------|---------|
| net user | Display local users |
| net user username /add | Create a new user |
| net localgroup administrators | Show Administrators group |

# 🛠️ Troubleshooting Commands

| Command | Purpose |
|----------|---------|
| sfc /scannow | Repair corrupted system files |

| ipconfig /renew | Renew IP address |
| ipconfig /flushdns | Clear DNS cache |
| shutdown /r /t 0 | Restart computer immediately |
