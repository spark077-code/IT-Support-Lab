# 🌐 Networking

Welcome to the **Networking** section of the **IT-Support-Lab** repository.

This folder contains beginner-friendly notes, practical examples, troubleshooting guides, and hands-on labs covering essential networking concepts. It is designed for students, IT Support professionals, Network Administrators, and Cyber Security learners.

---

# 📌 Objective

The goal of this section is to build a strong foundation in computer networking through structured documentation and practical learning.

Topics range from basic networking concepts to routing, switching, network services, and troubleshooting.

---

# 🎯 Learning Outcomes

After completing this section, you should be able to:

- Understand how computer networks operate
- Explain the OSI and TCP/IP models
- Configure IPv4 addressing
- Perform subnetting calculations
- Configure VLANs
- Understand switching and routing concepts
- Explain DNS and DHCP
- Understand NAT and ACLs
- Troubleshoot common network problems
- Build and test network topologies in Cisco Packet Tracer
